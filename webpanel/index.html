Сеть · Ethernet

Чтение сетевых параметров…

Изменение IP может прервать соединение. Откройте панель по новому адресу и подтвердите доступ в течение 90 секунд. Без подтверждения отдельный процесс вернёт прежние параметры. Настройки действуют до перезагрузки; автозапуск панели не делает сетевые настройки постоянными.

Пароль веб-панели

Не менее 12 символов. Этот пароль защищает веб-интерфейс; пароль root остаётся прежним.

Доступ к хабу

Системный пользователь admin имеет права root (UID 0). Доступ — через UART.

Автоматически скроется через 20 секунд. После смены системного пароля вне панели сохранённую копию нужно обновить.
Обновить сохранённую копию root-пароля

Если вы изменили пароль через UART, впишите новое значение сюда. Панель только запомнит его; системный пароль не меняется.

Дмитрий / 4VRS

Независимая надстройка к штатному ПО Aqara. Локальная веб-панель и MQTT-мост.

Заводские сведения и SDK

Модель устройства может отличаться от значения по умолчанию в общей заводской прошивке. Ключи и коды сопряжения здесь не показываются.



События публикуются в aqara/m2/zigbee/send. Настройки хранятся на хабе.
Проверка автозапуска… MQTT Discovery включается отдельной настройкой. Доступность отражает связь моста с брокерами, а не проверку каждого спящего датчика. Команды управления через внешний MQTT пока не включены.
